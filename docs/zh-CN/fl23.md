# FL2／FL3：准备、安装与核验

[返回首页](../../README.zh-CN.md) · [English](../en/fl23.md) · [开发指南](development.md)

本修复分支面向 **Sony A7C II／ILCE-7CM2 固件 2.01**，目前有离线软件证据，尚无新增的实机安装、启动、照片／视频或恢复验收。上游 Release 下载包不包含尚未合入的分支修改。

## 1. 确认机身和流程

在相机版本页面确认 **2.01**。兼容命令记录用户填写的版本，不会自动读取机身固件版本。准备可持续供电和可传数据的 USB 连接；安装要求实际电量至少 50%。

本分支使用显式 `prepare` → `install` → `verify`，已有 LUT 时也走此流程。它保留当前 LUT 槽位／路由，在实际程序上规划已核对的 FL23 曲线改动；发现字节冲突时停止准备。命令行会在安装前提示其他固件修改可能冲突。

双击 `FL23.cmd` 仍会打开重构后的图形界面。其中 `check`、`backup`、自动安装及旧还原入口属于早期原厂来源流程；备份按钮**不等于**兼容流程的显式 `prepare`。混装完整回退使用独立 [Recovery](recovery.md)。

## 2. 准备电脑

使用 Windows 和 64 位 Python 3.10+；图形界面还需要 Tkinter。启动器准备 Python、设备和编译依赖，详见[安装准备](manual.md)或[开发环境](development.md#4-开发环境)。

在完整源码根目录运行以下命令，不会连接相机：

```text
.\FL23.cmd --help
.\FL23.cmd --check
.\FL23.cmd --setup-only
.\FL23.cmd check-package
```

兼容流程需要完整工作区或包含它的工具包，包括 `dev/windows/` 和 `src/looks/`，不能单独复制启动器。旧 v2.2-preview.1 发布包与当前源码分支不是同一版本。

## 3. 连接相机并准备 USB 驱动

只连接一台受支持机身，选择 **大量存储／Mass Storage／MSC**，关闭其他相机工具。普通身份为 `054C:0E8A`，认证后可能重新枚举为服务身份 `054C:0336`。

当前 Windows 设备层接受 WinUSB、libusbK 或 libusb0，两种身份都需要可用驱动。使用 [Zadig](https://zadig.akeo.ie/) 时按准确 VID／PID 选择相机；服务身份可能首次认证后才出现。普通身份可访问不代表服务身份也可访问。

### 首次替换驱动后断开／提示「请检查所连接的设备」

替换驱动后，资源管理器可能不再显示普通相机盘符。仅凭屏幕提示不能确定故障原因。保留失败工作目录和日志，先核对当前 USB 身份，再决定是否调整驱动。如果首次准备仅因 0336 缺驱动而停止，应结束操作、配置该身份，并在弄清前次结果后再准备。旧 `check` 命令会认证进入服务模式，不是离线检查。不要连续点击安装，也不要把超时直接解释成必须重装驱动。

修复后的会话先核对 USB 产品字符串，直接认证，再从 AP 序列号绑定机身；不以存储就绪或 `getCameraInfo` 成功作为前置条件。认证或传输结果不明确时不自动重试。

## 4. 备份并生成候选

选择新的空白工作目录和另一份独立空白备份目录，建议两份副本位于不同磁盘，目录不能互相包含。将示例路径换成自己的路径：

```text
.\FL23.cmd prepare --firmware-version 2.01 --workspace "D:/CameraWork-A7C2-01" --backup-copy "E:/CameraBackup-A7C2-01"
```

此步骤会连接相机，读取程序／设置／资源，保存两份原始数据及独立完整存档，构建本机候选并执行临时原生预检查；不会安装程序或保存外观设置。要求成功到达 `prepared` 阶段。若已完整启用本版 FL23，工具保留现状，不重复安装。

保留两个完整目录、`state.json`、证据和 `checkpoint.private.zip`。单独复制候选或清单不能代替可恢复的机身备份。

## 5. 安装已准备的事务

使用同一工作目录，并填写**实际**电量；下面的 `82` 只是例子：

```text
.\FL23.cmd install --workspace "D:/CameraWork-A7C2-01" --battery-percent 82
```

工具在写入前核对机身、新鲜完整程序、目标设置和无关未保存配方，再写入计划窗口、完整读回、保存并核验选定色彩设置，处理保留启动镜像。所有 I/O 结束前保持供电和 USB 连接。

失败或结果未知时，依据保留证据诊断；不要手改阶段或重放安装器来强行完成。

## 6. 冷启动并核验

只有成功到达 `installed_pending_cold_start` 且全部 I/O 结束后，才断开 USB／其他外接电源、正常关机，等存取灯熄灭，取出电池至少一分钟。重新开机，分别检查名称、不按快门的预览切换、新拍 FL2／FL3／ST 照片及回放。接回 MSC：

```text
.\FL23.cmd verify --workspace "D:/CameraWork-A7C2-01"
```

核验检查当前 FL23 补丁、保存参数和已加载 AP 片段，允许后来安装的受支持 LUT，不执行重装。实际照片／视频观察要与字节读回结果分别记录。

## 7. 完整回退

使用独立 [Recovery](recovery.md)，选择原始完整存档或支持的旧备份，不要求 LUT Job。保留的原厂来源 FL23 还原辅助入口不适用于 FL23／LUT 组合镜像；不能把另一机身的设置／校准写入本机。

## 8. 已验证范围

见[开发验证](development.md#6-离线验证)和[更新日志](changelog.md)。两种安装顺序、曲线路由、单槽撤销及存档回退已有官方程序字节加模拟设置的离线证据。这不证明真实 USB 可靠性、启动安全、影像效果、长期稳定性或断电恢复。历史单机观察只属于对应的历史构建。
