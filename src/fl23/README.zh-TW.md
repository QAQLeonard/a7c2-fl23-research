# A7C II 2.01 · FL2／FL3 預覽版 0.5.2

> 历史组件／研究记录。当前修复分支的命令、构建和验证方法以[开发指南](../../docs/zh-CN/development.md)为准。来源署名与许可继续保留。

這是讓原版 Sony ILCE-7CM2（A7C II）2.01 使用 FL2／FL3 的實驗移植工具。**不是全面穩定版，也不是可放記憶卡更新的 BODYDATA.DAT。**

目前一台機身已完成程式與參數寫入、完整讀回；使用者確認取出電池後新選單出現，FL2、FL3、ST 都能拍攝新照片及在相機回放。這個整理後的圖形介面與通用流程尚未在第二台機身實測。完整驗證界限見 `VALIDATION.json`。

0.5.2 修的是「曲線根本沒被讀到」。0.5.1 上機後三個場景實拍，機內 FL2／FL3 的色調仍然落在 Adobe 的 **ST** 上（ΔL +2.53／−0.23），而不是 Adobe 的 FL2／FL3（−8.25／−9.50）。反彙編追出取用鏈：`0x323172`／`0x323298` 呼叫 `0x138832` 取得路由表基址，基址 `0x012099F8` 是對的，但該 helper 還帶了一段只在 `r4==0`（照片）時生效的程式，把 CP color 索引 19／20 改寫成 0，於是照片退回 `route[0]=(0,10)` →第 0 列 → 原廠 ST 曲線。0.5.2 把那 14 個位元組換成 NOP，保留基址載入與返回；原地改寫，26 位元組窗口與 56864 位元組模組長度都不變。cpapp-b.bin FINAL `a969a783…` → `30a59552…`。CP color 19／20 = FL2／FL3 已由 A7M4 方法 3 交叉驗證。詳見 `docs/fl23-v052-gamma-route-helper.md`。

0.5.1 只改 Gamma，依據是實拍對照：機內 FL2／FL3 相對 Adobe 的 `Camera FL2／FL3` 參考，在**線性光下是整體 ×0.67～0.70 的縮放，且 R／G／B 三通道一致**（原生 ST／FL 對照是 ×1.00）。單一縮放就能把殘差壓到 ΔL ≈ −1～−1.9、ΔC ≈ +0.2 —— 也就是先前量到的「中間調暗 8～10 L\*」與「彩度只有 0.68」是**同一個原因**，不是兩個問題。0.5.0 把照片槽 6 曲線只寫進 generation 6，而機身讀的是 generation 5（內部槽 0～5）；0.5.1 讓 **gen 5 與 gen 6 都寫照片槽 6 曲線**，無論機身讀哪一條都對。改動：Gamma 窗口 514→累計 510 位元組（相對 0.5.0），色彩資產完全不變。原因、判據與驗證界限見 `docs/fl23-v051-photo-slot6-tone.md`。

0.5.0 改兩件事，都從解包的 FX2 1.01 韌體直接取值，不再靠「沒有公開來源」的推導填充：

1. **Gamma 內部槽 6 改用照片曲線。** 0.4.0 把 FX2 的**影片**槽 6 曲線寫進 A7C II 的 generation 6 記錄；A7C II 原廠路由把 FL2／FL3 的照片與影片指到同一個 Gamma ID（0x30／0x31），所以照片也拿到影片曲線。0.5.0 換成 FX2 的照片槽 6 曲線（RAW 0x7806 對應的就是這一條）。
2. **矩陣改為逐槽複製。** 16 個槽不是溫度冗餘，是**色相分區**：A7C II 原生外觀每個端點內就有 15～16 個不同槽值，0x780F 也是按這 16 槽逐槽打包。0.4.x 把每端點 16 槽填成同一組係數，等於 16 個色相分區用同一個判讀——這正是「色相改不動」的成因。0.5.0 逐槽複製 FX2 的 48 組值。

色度一個位元組都沒動（FX2 差分值與 R5 公布值本來就逐項相同）。合計改動：色彩 669 位元組、Gamma 窗口 514 位元組。**尚未上機重拍或量測色彩**。原因、判據與驗證界限見 `docs/fl23-v050-gamma-and-perslot-matrix.md`。

0.4.0 只改矩陣的三個光源端點：0.3.x 把 A1 端點的六係數蓋進 B／A1／A2 三處，實拍回饋「紅橙已校準、綠色色相偏移不夠」與此相符。0.4.0 讓每個端點寫自己的六係數（B／A2 取自 A7M4 專案對 FX2 CP 的讀取），仍各自鋪滿 16 槽，共 528 位元組；色度、Gamma 與程式資產不變。**尚未上機重拍或量測色彩**。原因與預期方向見 `docs/fl23-v040-endpoint-matrices.md`。

0.3.1 只修「回復原版」的版本相容性與可重跑性，色彩與程式資產與 0.3.0 完全相同：FL2／FL3 的色度三組與**全部 48 個矩陣槽**（3 個光源端點 × 16 個溫度槽）為 A7R V 專案（`sony-a7r5-custom-firmware`）公布的 FL2／FL3 數值，共 795 位元組。

0.3.0 的回復流程會用「目前這個套件」重算應有的色彩單元，因此當機身裡裝的是**其他版本**套件寫入的色彩時，會以「CP 設定狀態未知」中止。0.3.1 改為檢查色彩寫入窗口以外是否與原版一致：任何一版套件寫入的色彩都能安全回復，窗口外有任何差異仍會拒絕。原因與判準見 `docs/fl23-v031-restore-version-mismatch.md`。

0.2.0 只換了每個端點的槽 0，其餘 45 槽仍是 Alpha 1 II 的矩陣，實拍會按色溫落到舊判讀上，出現「紅黃不夠偏橙、暗部不夠沉」；原因與修正見 `docs/fl23-v030-slot-fill.md`，移植範圍見 `docs/fl23-colour-port-from-r5.md`。0.1.0 至 0.3.1 的 ZIP 保持不變，可作對照與回退。

## 適用範圍

- Windows、Python 3.10 或更新版；首次安裝必要元件需要網路。
- 僅限 ILCE-7CM2，原始 AP／CP 完整檔案雜湊與本套件固定的官方 2.01 完全相同。
- 其他型號、其他版本、已改過的程式、已占用的新風格槽位會被拒絕。
- 需要可傳資料的 USB 線、相機「大量儲存」模式及對應 USB 驅動。

修改韌體有使相機無法正常開機的風險；斷電後救機尚未驗證。請保留原始備份及工作目錄，不要把此預覽版描述成任何機身都能安全刷入的通用韌體。

## 第一次使用

1. 先確認相機顯示版本2.01、電量至少50%。寫入期間不要關機或拔線。完成操作再拔線取出電池。
2. 用 Zadig 為這台 Sony 裝置的兩個身份安裝 libusbK：正常大量儲存 `054C:0E8A`、服務 `054C:0336`。第二個身份要在首次服務認證後才出現；若工具停止並提示0336驅動，安裝該身份後重新接回。只選此相機，不要替換其他儲存裝置或 PC Remote 身份的驅動。Zadig：[官方網站](https://zadig.akeo.ie/)。
3. 執行 `Start.cmd`。它只為此工具建立本機 Python 環境，然後開啟介面；不會自動寫相機。
4. 選一個新的空白機身工作目錄，及另一個空白備份目錄，建議放不同磁碟。
5. 按「1 備份與檢查」。它會讀取機身原始 AP、CP、自己的設定備份，核對型號／指紋、建立兩份備份、合併這台機身的新色彩單元，並在機內執行只校驗模式。此步不改寫程式檔或保存拍攝設定；會使用並清除指定臨時診斷模組。
6. 準備成功後，輸入實際電量，按「2 安裝預覽版」。這才會寫程式固定窗口、讀回、保存四項目標設定並處理舊開機快照。

原生服務驅動安裝仍需使用者操作；套件不自動改驅動、不改相機版本號、不做簽章繞過，也不提供 Sony 正式簽章更新包。

## 寫入完成後務必完整斷電

只有在工具顯示全部完成、沒有讀寫程序時：拔 USB、正常關機，等存取燈熄滅後取出電池約10秒，再裝回開機。**只切換電源開關曾讓舊的選單旗標留在執行期，新選單沒有出現；完整斷電後才出現。**

分別選 FL2、FL3，使用相機內建重設；預期八項值依序為 Contrast、Highlights、Shadows、Fade、Saturation、Sharpness、Sharpness Range、Clarity：`0,0,0,1,0,4,3,1`。這個工具沒有批量覆蓋使用者目前調整值。

各拍一張新的 ST、FL2、FL3，檢查回放。需要電腦端確認時，再接回並按「3 重開後核對」，會核對完整磁碟程式、保存參數與六個固定執行期區域。照片的實際色彩與拍攝組合仍需人工檢查。

## 原檔回復與錯誤處理

「回復原版」使用該機身工作目錄中的原始程式及四項目標設定；不覆蓋整份備份，不改CP unit00／02。回復前請先選ST、完整斷電開機後再連線。它要求目前程式完整符合本套件的已安裝版，未知或部分損壞的映像不會盲目修補。

只改色彩參數、不改程式的版本（0.1.0／0.2.0／0.3.x／0.4.0）之間，可以用**任一版**的回復流程收尾：工具只檢查色彩寫入窗口以外是否與原版一致，窗口內的差異屬於哪一版都接受。若中途中斷，重跑「回復原版」會依實際程式狀態續做，不會因為程式已回到原版而卡住。回復後同樣需正常關機並取出電池再開機。

若逾時、斷線、出現「結果未知」或 `needs_review`：保留工作目錄，不要直接重跑寫入或重新開機。工具停止後續命令，須先確認既有結果及目前檔案。這個預覽版沒有自動處理任意斷電／斷線後續裝的功能。

工作目錄及第二份備份包含私人設定，請不要上傳公開。分享本ZIP即可，不要把機身工作目錄加入ZIP。

## 命令列

```powershell
python app.py check-package
python app.py prepare --workspace X:\MyCamera --backup-copy Y:\MyCameraBackup
python app.py install --workspace X:\MyCamera --battery-percent 82
python app.py verify --workspace X:\MyCamera
python app.py restore --workspace X:\MyCamera --battery-percent 82
```

上面的路徑與82%是使用範例；請選自己的目錄並輸入實際電量。

「check-package」與離線測試不接觸USB。這不是自動對所有韌體版本重新定位的補丁器；跨版本須重新分析及實測。

色彩資產另有離線工具，不連相機：

```powershell
python fl23_color.py inspect   # 48 槽是否等於供體值、各端點不同槽值數
python fl23_color.py verify    # 核對 48/48 槽逐槽等於供體值、行和 1024、A1 與 R5 一致、清單雜湊自洽
python fl23_color.py hue --per-slot   # 逐色相分區的位移，以及與 0.4.x 全槽同值的落差
python fl23_color.py hue       # 端點之間對各色相角的位移對照（--json 可輸出）
python fl23_color.py port --write   # 依參考值重寫 colors.json（先印出將變更的位元組數）
```
